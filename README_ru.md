KMP приложение для начинающих художников, предоставляющее разные инструменты для создания цветовых палитр и визуализации.

## 📖 Описание

🎨 Редактор палитр
* Создавайте неограниченное количество цветовых палитр для ваших проектов.
* Добавляйте, удаляйте и изменяйте цвета внутри палитры.
* Экспортируйте палитры из фото, применяя разные алгоритмы извлечения цветов.
* Рекомендации гармонирующих с палитрой цветов.

📐 Конструктор перспективы
* Построение перспективных сеток с настраиваемым количеством точек схода и исходящих лучей.
* Готовые шаблоны для быстрого построения.
* Генерация сетки перспективы по загруженному изображению.
* Экспорт созданной сетки перспективы в изображение.

📦 Корзинка (Только под desktop)
* Временное хранилище для изображений из буфера обмена.
* Быстрая вставка изображений через Ctrl+V.
* Удобный просмотр хранящихся изображений.
* Копирование изображений обратно в буфер обмена.
* Возможность сохранения изображений между сессиями приложения.

🔬 Цветовая лаборатория (Beta)
* Небольшая 3D-сцена для оценки цветов.
* Изменяйте в реальном времени цвета объектов: цвет шара, поверхности и освещения.
